HOW TO RUN
================================================================================

QUICK START (Recommended):
1. chmod +x quick-start.sh
2. ./quick-start.sh
3. In Terminal 1: cd backend && source venv/bin/activate && python manage.py runserver
4. In Terminal 2: npm run dev
5. Visit http://localhost:3000

MANUAL START:

BACKEND:
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_sampradays
python manage.py seed_plans
python manage.py runserver
→ Backend at http://localhost:8000

FRONTEND:
cd ..
npm install
npm run dev
→ Frontend at http://localhost:3000

DEPLOYMENT STEPS
================================================================================

FRONTEND (Vercel):
1. git push origin main
2. Go to vercel.com, connect repo
3. Set NEXT_PUBLIC_API_URL to production backend URL
4. Auto-deploys on every push

BACKEND (Railway):
1. git push heroku main (or Railway CLI)
2. Set environment variables
3. Run: heroku run python manage.py migrate
4. Run: heroku run python manage.py seed_sampradays
5. Done!
